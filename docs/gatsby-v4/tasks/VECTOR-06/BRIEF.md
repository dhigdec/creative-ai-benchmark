# SB3-036-VEC | Ridgeway Rovers - Football crest master system

Recover a football crest and its hand-drawn shirt lettering

Ridgeway Rovers wants its existing identity back in usable form. The crest needs to work at breast size and in one ink; the lettering comes from a set of 1990s drawings rather than a font we can buy.

Scope
1. Football club crest: 3 named exports. The club lettering matches the source. The crest details remain recognisable at shirt size.
2. Club number glyph: 10 named exports. The numeral is unambiguous at kit viewing distance. The glyph follows the founder's drawing.
3. Club letter glyph: 26 named exports. The letter follows the founder's drawing. The letter has no graph-paper artefacts.
4. Shirt and training-kit artwork sheet: 1 named export. The crest placement respects the supplied kit dimensions. The name-number hierarchy is usable on the shirt.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
