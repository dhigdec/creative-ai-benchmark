# SB3-031-VEC | Cordwain Overland - Identity master graphics

Recover three apparel graphics and prove they survive small reproduction

Cordwain has lost the working artwork for three overland graphics. We need a vector specialist who can recover what is actually in the references and make a useful garment-ready family, not deliver an unchecked automatic trace.

What we need back
- Recovered garment mark: 3 named exports. The geometry follows the authoritative source mark. The lettering is faithful to the source.
- Garment graphics application sheet: 1 named export. Placement scale matches the supplied garment constraints. The specified ink count is respected.
- Garment lookbook layout: 1 named export. The garment and graphic relationship is visible. The identity is consistent with the recovered masters.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
