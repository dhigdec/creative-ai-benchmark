# SB3-066-LAY | Harborline Realty - Weekly listing sheet system

Restore a weekly property-sheet workflow from our retired printer's PDF

Every Monday, Harborline Realty prints a sheet for each active listing. The printer retired with the working file. We need the process rebuilt so the current list controls the output, while the starter homes and premium properties retain appropriate, distinct image treatments.

Scope
1. Weekly property listing sheet: 12 named exports. The photograph belongs to this listing. The listing status is current in the supplied register. The agent contact is clear.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
