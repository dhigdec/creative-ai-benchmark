Performer laminates for Lanternwood, rebuilt from last year's printed artwork

Twenty-two people need correct performer laminates. Our designer left in 2024, and the usable starting point is last year's printed artwork. We need a production designer who will rebuild the run carefully, not carry last year's names or fields into new passes.

The commission
