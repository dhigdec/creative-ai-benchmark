# SB3-016-PHO | SlabVault - Collectible card marketplace image system

Consignment listing photographs where the holder and label remain legible

SlabVault handles graded collectibles. A listing photograph has to show the item and the evidence around it: holder, label and seal. Glare is a problem in the current set, but we cannot replace unreadable information with a convincing guess.

Please prepare
- Collectible listing tile: 14 named exports. The pictured card and visible holder label match this lot record. Source condition defects remain visible.
- Collectible condition-detail tile: 14 named exports. The grader, grade and certification number appear in the caption block. The photograph does not imply a different grade.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
