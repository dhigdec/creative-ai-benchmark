# SB3-009-PHO | OSTRA - Restaurant plate photography system

OSTRA tasting-menu images: dark, precise and still appetising

OSTRA is a 22-seat tasting counter. We have thirteen plate photographs from two services, and we need them to feel like the same room and the same menu. Dark should not mean muddy; glaze and food texture still need to read.

Deliverables
1. Seasonal menu announcement: 1 named export. OSTRA is identified. The featured dish agrees with the seasonal menu. The reservation action is visible.
2. Booking-page dish tile: 13 named exports. The caption correctly identifies the pictured dish. The food is recognisable at mobile listing size.
3. Reservation story: 1 named export. The booking action sits within the defined safe area. The restaurant name is readable at mobile size.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.
