# SB3-060-LAY | Aldervale Mutual - District insurance counter-card run

Rebuild our insurance counter-card template and produce the district run

The printer who made Aldervale Mutual's counter cards has closed. We still have the press file and need a reusable production route, not a one-time approximation of the design.

Scope
1. District insurance counter card: 14 named exports. The compliance wording, meaning the record's Disclosure Text, is reproduced without alteration. The contact information, meaning the record's Office, belongs to this producer. The complete Disclosure Text remains inside the card trim. The card carries no district line; none of the supplied records names a district.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. Set the rebuilt card in the attached brand identity's type system and colours; the old press file shows which fields the card carries, not its typefaces, type sizes or rule positions. The license line and office are set as body text. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
