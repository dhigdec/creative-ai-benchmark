# SB3-060-LAY | Aldervale Mutual - District insurance counter-card run

Aldervale Mutual producer counter cards

The printer who made our counter cards has closed. We have the last press PDF and need a reusable layout rebuilt for this year's producer run.

Please prepare thirteen individual producer-card PDFs and one combined thirteen-page PDF, using the names and record assignments in the requested deliverables. That is fourteen PDF files in total.

For each card, use the correct producer and Office information from producer_roster_northern.csv. Reproduce the full Disclosure Text exactly, without shortening it, and keep it inside the card trim. Do not add a district line; the supplied records do not name a district. Follow compliance_note.txt for permissions and restrictions.

The old press file shows which fields belong on the card. It is not the typeface, type-size, colour or rule-position standard for this run. Use the attached Aldervale identity and set the licence line and office as body text.

Deliver the named individual PDFs and combined PDF at the specified 148 x 210 mm trim size. The supplied press file and roster should guide a consistent layout across the run.
