# SB3-054-LAY | Nimbadesk - B2B sell-sheet system

Nimbadesk launch collateral using the current product build

We need the sell sheets, pitch deck and launch social to look like one product. Each sell sheet, the deck's opening page and each launch post carry the Nimbadesk mark from nimbadesk_logo_v4.png. There are eleven product captures in the pack, but the first job is to establish which belong to the current build and how they should be presented consistently.

Scope
1. B2B product sell sheet: 4 named exports. The stated metric preserves its qualification: its mono measurement line gives the window the figure covers, as our supplied files state it. The UI is a faithful supplied capture from the current build, showing the feature its sheet's copy block describes. Each sheet carries one approved sell-sheet block from nimbadesk_copy.txt, word for word, in the order given there: Median first response time with Unified Queue, Tickets resolved per agent with SLA & Routing, Customer satisfaction (CSAT) with Reporting for Directors.
2. Product pitch deck: 1 named export. The narrative explains the customer problem before the offer. The claims follow approved copy.
3. Product launch post: 3 named exports. The product name is clear, and each post shows what it is named for: Workflow our queue and routing, Reporting our director reporting, each in a current-build capture, and Team the people behind Nimbadesk, from the supplied booth headshots. The request-demo action is visible: our approved 20-minute walkthrough line from nimbadesk_copy.txt, word for word.

Use the supplied approved copy and factual records. Wherever a metric appears, in the deck or a post, it carries the same window as on its sell sheet. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
