# SB3-040-VEC | Evergreen Provisions - Restored crest system

Six painted crest lockups prepared for an apparel capsule

Evergreen Provisions needs the six painted crest lockups prepared for its small garment capsule. The brush character matters, but the artwork must hold at the actual garment width rather than only in a large presentation.

Please prepare
- Apparel crest production artwork: 6 named exports. The crest matches the authoritative painted reference. The brush character survives the reduction to each export's print width in evergreen_plate_schedule.csv (print_width_in), and each file is set to that width.
- Garment capsule application presentation: 1 named export. The graphic placement follows the garment schedule, and each application states its schedule placement and print width. The presentation distinguishes print artwork from illustrative mockup; where no photograph of the printed side was supplied, the application is shown on a drawing labelled as illustrative mockup. Painted crest lettering is never retyped inside a crest; outside the crests, design names may be set as capsule titles and in spec copy.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
