# SB3-031-VEC | Cordwain Overland - Identity master graphics

Recover three apparel graphics and prove they survive small reproduction

Cordwain has lost the working artwork for three overland graphics. We need a vector specialist who can recover what is actually in the references and make a useful garment-ready family, not deliver an unchecked automatic trace.

What we need back
- Recovered garment mark: 3 named exports. The geometry follows the authoritative source mark: the graphic's own flat web export, or its bench sample photograph where one exists, with nothing added that neither shows. The lettering is faithful to the source: it carries every word of the graphic's own flat web export, spelled as there, drawn as in its source and not reset in the brand type system.
- Garment graphics application sheet: 1 named export. Placement scale matches the supplied garment constraints: each graphic sits where it printed on its bench sample or on the printer submission sheet, no wider than the brand sheet's maximum print width for that graphic, its hoodie badge width for a badge and otherwise the width for its placement. The specified ink count is respected: no graphic is specified in more than three inks.
- Garment lookbook layout: 1 named export. The garment and graphic relationship is visible for each of the three recovered marks. The identity is consistent with the recovered masters.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
