# SB3-056-LAY | Lanternwood Folk Fest - Performer credential system

Performer laminates for Lanternwood, rebuilt from last year's printed artwork

Twenty-two people need correct performer laminates. Our designer left in 2024, and the usable starting point is last year's printed artwork. We need a production designer who will rebuild the run carefully, not carry last year's names or fields into new passes.

The commission

 Festival access credential: 22 named exports. The name, act, role, access areas and days on site match this person record; the holder's name is the credential's one name line, for crew, volunteers and vendors too, and the act runs beneath it in the text face. When a headshot is supplied, it belongs to the named person; otherwise the credential carries no portrait or photograph, neither generated nor cut from another supplied picture. The credential remains readable when worn, and carries the festival mark and the two sponsor lines from the approved billing, word for word.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
