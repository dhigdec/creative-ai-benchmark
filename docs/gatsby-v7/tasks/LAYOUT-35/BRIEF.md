# SB3-080-LAY | Marrow and Vane - Exhibition wall-label system

Exhibition wall labels, reconciled artwork records and installer files by room

Marrow and Vane is hanging thirty-nine approved works. Reuse the spring printer's label construction (its card, its small type set high with unprinted stock beneath and its picture well below the type, but with the type itself set in the attached brand identity's type system rather than in the spring card's face, line order or accession colour), reconcile the interns' two photo shoots to the accession register, and package the final labels in the approved clockwise room order.

The commission

 Exhibition wall label: 40 named exports. The work identity matches this accession record, and the label carries that work's own reference photograph in the spring card's picture well, below the type. The artist attribution is accurate. Each artist's name keeps the register's spelling and case in the file's text, on the labels, installer files and checklist alike; the capitals the type system asks for are applied as a display style, not typed in. The curatorial text is readable at installation distance. Year, medium, dimensions and any credit line are set character for character as the registrar entered them in mv_autumn_works.csv.

 Room installer label file: 3 named exports. Supply one installer file per room in the approved clockwise hang order.

 Exhibition desk and press checklist: 1 named export. The checklist has separate sections for The Front Room, The Cabinet and The Long Gallery, each listing its works in hang order, and every entry gives the work's catalogue number, artist, title, year, medium, dimensions, any credit line and accession number beside a small reference picture. The checklist also carries the show's title and dates, as mv_desk_note.txt gives them. The press contact is exactly “press@marrowandvane.example”.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
