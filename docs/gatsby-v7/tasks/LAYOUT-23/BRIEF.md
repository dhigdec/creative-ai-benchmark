# SB3-068-LAY | Meridian Summit - Conference badge and wayfinding system

Eighteen conference badges with portraits that match and records that do not drift

The Meridian Summit registration desk needs a correct badge for every attending delegate. We have eighteen self-submitted photographs and last year's venue-bureau PDF, but not its working file.

The commission

 Conference delegate badge: 20 named exports. The access category, the ticket type in the registration, matches the registration, and the badge also carries the delegate's name, organisation and track exactly as registered. When a headshot is supplied, it belongs to the named delegate, is balanced to the one neutral white balance the whole portrait set shares, and is cut out onto the same plain Warm Stone ground as every other portrait; otherwise the badge contains no invented portrait. The delegate name is readable when worn, and every badge carries the summit mark.

 Conference track direction sign: 3 named exports. The track names follow the approved track note: each sign names its destination (Registration, Main stage or Breakouts) as its largest line, set in Founders Grotesk Regular, with the three tracks listed beneath it. The arrow points in the specified direction: left on the Registration sign, up (straight ahead) on the Main stage sign and right on the Breakouts sign.

Use the supplied approved copy and factual records. Permission restrictions in the owner's notes take precedence over inclusion in a source table.

Use the attached brand identity and the source files listed in the asset manifest. The output register defines exact filenames, pages, sizes and record bindings. Supporting previews are welcome but cannot replace those files.
