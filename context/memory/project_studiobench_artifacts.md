Three hard lessons from the pilot (all fixed in generate_ao.py):
1. **Image models leak REAL trademarks** — gpt-image-2/gemini reproduced Wicked Weed, Gildan, Taylor Stitch, Abercrombie, Japan Blue, Flint&Tinder, IWC, Kia, Dawn onto generated assets. FIX: every gen prompt now carries an `ANTIBRAND` clause + the QC panel fails any REAL brand + a gemini `brand_scan` gate re-rolls leaks. MUST brand-scan all generated assets — the whole benchmark is licensing-clean. (Fictional brands e.g. the task's own wordmark are FINE.)
2. **Intent-aware QC** — many inputs are DELIBERATELY imperfect (retouch/audit tasks: tilt, cast, print-unsafe tones, halos). Judging them as finished deliverables false-fails them. Criteria must say "SOURCE file, don't penalise the intended imperfections."
3. **Adapters take a logger OBJECT (`.log`), not a function** (passing a fn crashes on transparent assets); **gpt-image-2 rejects `background=transparent`** (route transparent→gemini); **Claude vision 400s on large images** (downscale ≤1536 before judging); **partial re-runs overwrite manifests** (skipped assets drop from qc_summary — rebuild manifests from disk after any subset re-run).
