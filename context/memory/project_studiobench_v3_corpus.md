The **V3 rebuild** of the StudioBench creative-agent benchmark ([[project_adobe_benchmark_rebuild]], [[project_studiobench_input_assets]]). Generated ~2026-09-10/11. Lives at `Deccan/Adobe-Freelance-Leads/complex_benchmark/adobe_only/`.

**What it is:** 100 new task specs, family-prefixed IDs (PHOTO-01..30, VECTOR-01..15, LAYOUT-01..35, MOTION-01..20) — replaces the old `AO-*` naming. Distribution hits the mandate exactly: Photo 30 / Vector 15 / Layout 35 / Motion 20.
- `specs_v3/*.json` (100 files, ~42KB each) = per-task specs. `TASKS_V3_ALL100.json` (4.7MB) = the same 100 banked as one list. `TASKS_V3_BANKED.json` = an 11-task earlier batch. `EXEMPLARS_V3_VALIDATED.json` / `EXEMPLARS_DEEP_ORCHESTRATION.json` / `EXEMPLAR_COMPOSITE_BRIEFS.json` = seed exemplars defining the standard.
- Spec schema (20 fields): new_id, family, engagement_title, vertical, real_brief_anchor, client_one_liner, client_brief, price_band_and_audience, brand_identity, assets_supplied, acceptance_bar, adobe_surfaces, trajectory, emergent_checkpoints, deliverables, verifiers_auto, verifiers_human, decision_gates, why_not_vlm, doability_proof.

**"Complex functions" = the connector orchestration.** Per task: **4–6 Adobe surfaces (avg 5)**, **14–21 trajectory steps (avg 17.5)**, **exactly 3 `emergent_checkpoints`** (runtime traps only discoverable by RUNNING — e.g. remove_background silently downscales oversized inputs; importer drops filter:blur & truncates multi-layer box-shadow; subject crop mis-locks on sparse macro art), 4–6 deliverables, 6–11 auto verifiers, 5–9 human verifiers, 9–17 decision gates. `adobe_surfaces[].tools` lists the actual MCP function names. Surfaces: Express+Fonts in all 100; Photoshop/Lightroom 97; Stock/Boards 65; InDesign data-merge ~49; Premiere video ~14+6.

**Design standard** (from `REWORK_GUIDANCE.md`, `REBUILD_HARDNESS_BAR.md`, `REBUILD_GROUND_TRUTH.md`, `CONNECTOR_CAPABILITIES_v3.md`): every task is a full freelance commission (small ops are STEPS); hardness = decision-density not step-count; must fail a one-shot VLM regen on identity/spec/editability; agent NEVER measures a pixel/hex (grader does); briefs state goals not methods; only verified connector tools; IP-safe (laundered brands). Composition engine = HTML→Express authoring for designed collateral, InDesign data-merge only for true record-per-page runs.
