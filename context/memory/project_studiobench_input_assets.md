Generated the INPUT ASSETS (the photos/logos/videos/audio/data a client hands a freelancer) for all **100 StudioBench tasks** (specs: `Adobe-Freelance-Leads/complex_benchmark/adobe_only/specs/AO-*.json`). Assets live per-task under `Adobe-Freelance-Leads/input_assets/AO-XX_<slug>/assets/` with a `manifest.json` each. Status **2026-07-07: 100/100 tasks complete** — 462 real generated assets (24 video, 29 audio, 284 image, 79 data) + 46 native-format proxy stand-ins.

**Pipeline:** `Adobe-Freelance-Leads/asset_pipeline/` (has `.venv`, `.env` with GEMINI/OPENAI/ANTHROPIC/FAL keys, `adapters/`). Run scripts as `.venv/bin/python <script>`.

**Model routing:** logos/wordmarks/UI/text → `gemini-3-pro-image` (Nano Banana Pro); photoreal → `gpt-image-2`; video → **Seedance 1.0 Pro via fal.ai** (`fal-ai/bytedance/seedance/v1/pro/{text,image}-to-video`, 1080p ~5s, SILENT); speech audio → `gpt-4o-mini-tts`; **music → fal Stable Audio** (`fal-ai/stable-audio`, params `seconds_total`+`steps`; adapter `adapters/music_gen.py`, CLI `gen_music.py --task --out <relpath-under-assets> --prompt "instrumental…no vocals" [--seconds N]`) — built 2026-07-07 because the pipeline had TTS only; judges → gpt-4.1 + gemini-2.5-flash + claude-sonnet-4-6; transcribe → gpt-4o-transcribe.

**4-layer checks loop** (all in the workflow agents): (1) `verify_assets.py` — 3-model MAJORITY acceptance (pass iff ≥2/3 judges ≥8 + brand-clean); (2) `realism_audit.py` — 2 vision models flag AI-careless; (3) `consistency_audit.py` — brief-aware cross-asset brand consistency (multi-brand projects → consistent=true; only single-brand assets that disagree get flagged); (4) AV-specific — video frame→vision panel (motion-aware: motion blur/foreign signage OK, only real trademarks fail), audio→Whisper transcript vs script.

**Single-asset fix helpers:** `gen_one.py` (image, `--model gemini|openai`), `gen_video.py` (Seedance clip, `--ref` = image-to-video from a still), `gen_ref.py` (brand-kit: regenerate conditioned on a master mark), `gen_music.py` (fal Stable Audio instrumental), `vframe.py` (extract a video frame for an agent to Read), `spec_of.py <TID>` (prints the task brief + the SPEC requirement for every input asset — what each MUST be; use to judge "meets requirements"). All gen_* append an ANTIBRAND clause.
