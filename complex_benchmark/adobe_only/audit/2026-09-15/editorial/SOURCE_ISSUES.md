# Existing Source Issues Not Changed By This Editorial Pass

The briefs have been rewritten against the current deliverable specifications. This pass changes only client-facing prose and marketplace titles/overviews. It does not certify that every underlying benchmark contract is internally consistent or executable.

## Canonical Names

- SB3-015-PHO is named a watch campaign, but its brand, assets and deliverables describe Summit & Sable recovery/overlanding gear. The new marketplace title and brief correctly describe the gear commission; the stable task name and storage path were left unchanged.
- SB3-022-PHO is named an outerwear image system, but its current context and deliverables describe the Nordhaven hotel. The new marketplace title and brief describe hospitality imagery; the stable task name and storage path were left unchanged.

## Delivery Contracts

- SB3-012-PHO D2, SB3-014-PHO D1, SB3-015-PHO D3, SB3-047-LAY D4 and SB3-072-LAY D3 contain vector-production language inside a primarily photographic deliverable. It has not been deleted from the briefs because doing so would conceal a contract requirement from the participant while retaining it in the benchmark specification.
- SB3-063-LAY D1 combines a generic template specification with a vector-production requirement. Both remain visible. The actual editable campaign outputs need to be judged against the full named scope, not a single generic template export.
- Several motion deliverable names suggest more outputs or richer media than their current specifications require. Examples: SB3-081-MOT D1 names master, vertical and square while the spec asks for one reframe; SB3-089-MOT D1 similarly names upright and square; SB3-090-MOT D1 names three vertical cuts while the spec describes one bounded edit plus a reframe. The new prose uses the current numerical specification and states source-duration and audio limits. These names should be reconciled with the contracts before freezing a scored study.
- Some motion verifiers still reflect those older output names. In SB3-081-MOT, for example, A4 and H1 expect both vertical and square versions even though the current D1 specification asks for one reframe. These checks were preserved, not silently weakened; they need a separate scope-and-verifier reconciliation before scored execution.
- Several supporting design deliverables group multiple named pieces under the same generic template specification. The rewritten briefs retain those names explicitly, but an editorial pass cannot establish missing quantities, page counts or export specifications that the underlying contract does not supply.

## What The Checks Establish

All 100 briefs and marketplace titles were individually rewritten. All 251 complete technical delivery specifications are represented, with limited readability substitutions documented in the build script. Brand identities, assets, source provenance, deliverable records, verifiers, task IDs, connector profiles, commercial terms and handover requirements are unchanged.

No creative task execution, new asset generation, asset-quality certification or verifier-calibration experiment was performed during this editorial pass. No claim of perfection follows from a schema or preservation check.
