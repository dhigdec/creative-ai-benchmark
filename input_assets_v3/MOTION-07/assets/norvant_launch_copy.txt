A NOTE ON THE MARK
The mark is a hexring glyph beside the wordmark NORVANT, cut in slate. The only place it still exists at any size is the sign on the reception wall; the original files went with the agency. Recover it off the sign — do not redraw it into a font and do not regenerate it. The ring is a ring: it has to still read as a ring at the size it prints on a card and reversed on the amber ground, not a filled hexagon.

A NOTE ON THE TYPE
One quiet type system: a plain neutral face for detail and body, a measured companion for headings. Nothing expressive, nothing decorative. This typography reaches the announcement set. The printed city cards carry the printer's own faces from last year's file, so say so in the note rather than pretending one system covers both.
