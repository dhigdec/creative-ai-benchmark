EMBERLINE - what our on-air graphics used to be set in
(from memory - I didn't build the old kit, I'm going off the previous designer's note and what stuck in my head. None of this is exact.)

SHOW NAME / ENDBOARD: a warm, soft SLAB - friendly, a bit rounded at the corners, not stiff. The old file called it something like "ROSELAWN slab", I think the semibold or the bold. Set in caps on the endboard.

STRAPS & CAPTIONS: a rounded geometric sans. Two names are stuck in my head and I honestly can't tell you which one it was - "Marlowe rounded" and "that Beaufort one, Beaufort Sans?". One of those. Set Regular for the body of the strap and a heavier cut up top.

SMALL PRINT / LOWER-THIRD DETAIL: the same rounded sans, Light or Regular, small.

WEIGHTS: we only ever said "medium" and "bold" out loud - never the 400 / 700 numbers, sorry. Whoever builds the kit will have to look up what those actually are per family.
