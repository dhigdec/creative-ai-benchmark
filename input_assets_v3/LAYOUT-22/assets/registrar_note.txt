CEDARLINE INSTITUTE - autumn cohort, note from the Registrar's office (Helen Abbott)

For whoever is setting the credentials this year. Read this before you touch the export.

THE TWO PROGRAMMES
We run one subject, Professional Practice, at two very different registers, and they must never come off the press looking like the same document.
- The Community Evening Programme. A hundred and eighty dollars, one evening a week, mostly younger working adults. The credential is a Certificate of Completion. It is a warm, plain, honest thing and it goes on a kitchen wall. In the export these carry a programme code beginning CPE.
- The Executive Programme. Nine thousand dollars, bought by the candidate's employer, and the diploma ends up framed in an office where that person's own clients read it. It is a Diploma, heavier and more formal, and it is the one the sponsoring firms judge us by. In the export these carry a programme code beginning CXP.
There is no separate column that tells you which is which. The code is the only place it lives, so split the cohort off the code and nothing else.

WHO SIGNS WHAT
- Community certificate: two signatures - Helen Abbott, Registrar, and Callum Reyes, Community Programme Lead.
- Executive diploma: two signatures - Dr Miriam Voss, Director of Executive Education, and Helen Abbott, Registrar.
The signature lines are already on both old press files. Do not move them.

HONOURS
The executive diploma carries an honours line: With Distinction, With Merit, or Pass, and the grade is in the export for those candidates. Set it exactly as recorded.

NAMES
Every name is set the way that candidate spells it, accents and all. We have had complaints from graduates whose names were flattened. If a name looks as though an accent has been dropped or spelled around, ask me before you print it - do not guess.

THE SPONSORS
Two autumn cohorts ago a sponsoring firm told us the executive diploma looked like something printed off a website. That is the single thing we cannot repeat. If the executive credential reads like the evening certificate in a frame, we will hear about it within the week.

THE SEAL
The seal is ours - it is the Institute's own device, the cedar and the founding year, 1978. It is not to be reinvented or redrawn from imagination. Whatever seal ends up on these credentials has to be our seal, the same one pressed into the certificate on the wall of the hall.

CORRECTIONS
Names get corrected right up to the morning of the ceremony. Whatever the programme and the card are built in, I have to be able to open them and fix a spelling myself an hour before we start.

Learning that holds up. - H.A.
