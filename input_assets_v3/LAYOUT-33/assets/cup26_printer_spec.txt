CONTINENTAL CUP 2026 — CARD PRINTER SPEC (what we and the licensing partner need back)

TRIM & STOCK
- Card trim: 63.5 x 88.9 mm portrait (2.5 x 3.5 in), the same as last season's team-set file.
- BLEED: we require 3 mm bleed on all four sides on the press-ready file. Note: last season's PDF was supplied with no bleed box; if you build off it, tell us plainly what can and cannot be done about bleed.
- Print resolution: 600 dpi at trim. A full card at trim is therefore 1500 x 2100 px.

FRAMES (as we hold the geometry; confirm against the converted document)
- PHOTO frame: 52.0 x 74.0 mm, i.e. about 1230 x 1748 px at 600 dpi. Placed photography must reach this at native scale. Do NOT upscale to fill it — a soft interpolated card is a reject.
- MARK frame: 9.5 x 9.5 mm, top-left, i.e. about 224 x 224 px at 600 dpi. The mark prints reversed on the dark field. It has to still read as our mark at that size.
- Text: player name, squad number, position, club line, set year are five separate fields.

ORDER
- The press file runs the WHOLE STOCKED SQUAD, one player per page, in SQUAD-NUMBER ORDER (1, 2, 3 ... ascending). The roster export is not in that order. Do not ship it in the order it arrived.

PROOFS
- Proofs for licensing sign-off must be rendered at 600 dpi at trim (1500 x 2100 px), embedded density set. A screen-scale page raster is not a proof.

PER-PLAYER FILES (the partner distributes these individually)
- One single-card PDF per stocked player, named: CUP26_<squadnumber-2digit>_<Surname>.pdf (e.g. CUP26_07_Ferraz.pdf, CUP26_09_Okoye.pdf). The name on the file MUST be the player on the card inside it — the partner keys distribution off the filename, so a mislabelled file ships to the wrong channel.

DELIVERY
- One ordered multi-page press file, eighteen named single-card files, the proofs, and a note of anything about this spec the supplied file cannot meet.
