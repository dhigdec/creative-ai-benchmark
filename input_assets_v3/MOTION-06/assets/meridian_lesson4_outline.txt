MERIDIAN ACADEMY - Operations Analytics for Working Managers
Lesson 4: Reconciling the Numbers (approved outline, written before recording)

This is the plan we shot from. Roughly forty minutes. Plain and unhurried, talking to a peer.

Beat 1 - Where the gap comes from
Objective: the learner can explain why the ledger and the operational feed never agree on the first pass, and name the three causes - timing, mapping and manual edits.

Beat 2 - Lining up the two sources
Objective: the learner can set the ledger balance and the ops-feed balance side by side for the same period and say which figure each system is authoritative for.

Beat 3 - Building the reconciliation model (the roll-forward)
Objective: the learner can build a roll-forward that bridges last month's agreed closing balance to this month's, posting each movement once in date order so the ending figure traces back line by line. THIS IS THE HEART OF THE LESSON.

Beat 4 - Setting a materiality threshold
Objective: the learner can choose the dollar line below which a reconciling difference is logged but not chased, so the hours spent investigating never cost more than the variance itself.

Beat 5 - Working one real exception end to end
Objective: the learner can trace a single variance to its cause using a real worked example (the recorded customer call), and decide what carries forward and what does not.

Beat 6 - Handing it to your manager
Objective: the learner can present the reconciliation as a one-page bridge, every line explained, rather than a raw spreadsheet.

Keep it plain. No slides-with-arrows, no hype. This is the lesson people stop on, so slow down and make the walkthrough land.
