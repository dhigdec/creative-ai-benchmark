Lumen QuarterlyHouse Style3
Type by role

Typography rules

Display / masthead: Alder Display Light.

Body: Wickley Text 9.5 / 13, measure 58 mm, roughly 62–66 characters.

Captions & credits: Coble Grotesque 7 pt. Caption sits tight under the picture edge, one line.

Folio: Coble Grotesque small caps.

One type system across the whole issue. The reader should recognise Lumen before reading a word.
